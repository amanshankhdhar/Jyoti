# Jyoti 🪔
Open-source flashlight + Quick-Settings tile for Android — built for phones
where the stock flashlight tile is dead/faded (e.g. ColorOS bug).
- LED torch via Camera2 (zero-permission on AOSP)
- Own QS tile (like ProtonVPN) + one-tap add on Android 13+
- Screen-light fallback, Hindi app name, works down to Android 5
